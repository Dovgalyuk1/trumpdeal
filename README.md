# TRUMPDEAL — The Greatest Deal Ever Made

Одностраничный лендинг мемкоина $TRUMPDEAL. Чистый статический HTML/CSS/JS, без сборки.

**Лор:** он нашёл единственную вещь в стране, у которой не было владельца — самого себя.
Присвоил себя утром во вторник, к обеду продал обратно Америке. Величайшая сделка в истории.

**Мини-игра:** THE NEGOTIATION DESK — торг на 8 раундов, где любое действие покупателя
поднимает цену. Каждый раунд открывает пункт договора, финал — рукопожатие и дождь денег.

## Настройка
В начале `index.html` блок SETTINGS:
```js
window.CONTRACT = "";   // адрес контракта
window.TWITTER  = "";   // ссылка на X
window.BUY_URL  = "";   // ссылка на покупку (пока пусто — кнопка BUY неактивна)
```

## Структура
- `index.html` — весь сайт
- `assets/` — вырезанный персонаж и кропы
